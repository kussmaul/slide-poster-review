# CEFR word lists

Used by `scripts/readability.py` (rubric item RD-1). The files are unchanged copies from
Open Language Profiles: https://github.com/openlanguageprofiles/olp-en-cefrj (retrieved 2026-11-25).

- `cefrj-vocabulary-profile-1.5.csv`: The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono,
  Tokyo University of Foreign Studies (http://www.cefr-j.org/). Free for research and commercial
  purposes, provided that the dataset is cited. Copyright Tono Laboratory, TUFS.
- `octanove-vocabulary-profile-c1c2-1.0.csv`: Octanove Vocabulary Profile C1/C2, version 1.0,
  by Octanove Labs (http://www.octanove.com/). Licensed under Creative Commons
  Attribution-ShareAlike 4.0 International (https://creativecommons.org/licenses/by-sa/4.0/).

Neither CEFR-J nor Open Language Profiles is responsible for any inaccuracies in the data.
