# Judged-item evals

Reports from `tools/eval_judgments.py check --save NAME`, one per blind eval: fresh agents judge
anonymized copies of the generated decks, and the report compares their levels with the
expected ranges. Each report names the commit and deck hashes it was prepared from; the decks
themselves are regenerated by `tools/make_test_decks.py`. Summaries are under task 25 in QUEUE.md.
